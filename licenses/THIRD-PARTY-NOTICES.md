# Third-party notices

This file lists the license texts and notices that Cubiq ships for code of other projects whose own files do not
carry them all: the bundled libraries whose jars contain no license or notice file, libraries whose jars lack
notices that apply to them or do not say where their source code is, and code of other projects that is compiled
into the server jar or the Paperclip jar itself. The files are in the folders of `third-party/` next to this file,
as their projects publish them; each was taken from the source given below, usually a commit of the project's
repository. Libraries whose jars contain all the license texts and notices that apply to them are not listed
here. The source code of the libraries under licenses that require it to be available, such as the GPL, the LGPL
and the MPL, is available from the repositories and commits given for them.

This file is generated by `scripts/library-licenses.py --notices` from `scripts/library-notices.json`.
