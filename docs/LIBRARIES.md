- `com.mysql:mysql-connector-j` 9.2.0: GPLv2-only code cannot be combined with GPLv3 code by itself; Oracle's Universal FOSS Exception is meant to allow distributing it together with other open source software. Whether it covers Cubiq's distribution is not confirmed. Paper bundles the same library.
- `net.md-5:bungeecord-chat` 1.21-R0.2-deprecated+build.21: BungeeCord's license, which covers its chat module, is the BSD 3-Clause License with an additional clause: "You may not use the software for commercial software hosting services without written permission from the author." Such a restriction is not part of an open source license, and the GPLv3 does not allow further restrictions. Spigot's and Paper's APIs expose this library, and Paper bundles it as well.
- `org.eclipse.sisu:org.eclipse.sisu.inject` 0.9.0.M2: The FSF lists the EPL 1.0 as incompatible with the GPL. Paper bundles the same library as a separate jar. See the open questions in LICENSING.md.

- `com.velocitypowered:velocity-native`: Velocity is licensed under the GPLv3; its native module has no license of its own. Its native libraries contain libdeflate (MIT) and use the operating system's OpenSSL, which is not bundled.
- `studio.cubiq:cubiq-api`: Paper's API with Purpur's and Cubiq's changes, distributed under the GPLv3 like the server.
