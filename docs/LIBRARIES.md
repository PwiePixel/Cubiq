# Bundled libraries

Generated by `scripts/library-licenses.py` from the Paperclip jar; do not edit this file by hand. After a dependency
or upstream update, regenerate it with `scripts/library-licenses.py cubiq-server/build/libs/cubiq-paperclip-*.jar >
docs/LIBRARIES.md`. CI fails when this file is out of date, when a library has a license that
`scripts/library-licenses.json` does not cover, or when the license notices of a library are missing. See
[LICENSING.md](LICENSING.md) for how the licenses fit together.

The license is taken from `scripts/library-notices.json` for the libraries that have an entry there, where it was
determined from the library's source at the bundled version, including code of other projects that the jar
contains; otherwise from the library's Maven POM or from its nearest parent POM that declares one. `allowed` means
that the license is compatible with distributing the server under the GPLv3; `open` marks a question the Cubiq
maintainers still have to answer before a release. The notices column says where the license texts and notices of
a library are: `in its jar` means that the jar contains a file named like a license or notice (LICENSE, NOTICE,
COPYING or COPYRIGHT), which the script does not check for completeness; the named folders are in
`licenses/third-party/`, which the server jar and the Paperclip jar contain under `META-INF/license/` together
with [THIRD-PARTY-NOTICES.md](../licenses/THIRD-PARTY-NOTICES.md). Where the files in a jar were found to lack
notices, or to lack where the source code is, the library has an entry in `scripts/library-notices.json` as well.

## Notes

- `net.md-5:bungeecord-chat`: BungeeCord's license, which covers its chat module, is the BSD 3-Clause License with an additional clause: "You may not use the software for commercial software hosting services without written permission from the author." Such a restriction is not part of an open source license, and the GPLv3 does not allow further restrictions. Spigot's and Paper's APIs expose this library, and Paper bundles it as well. The jar also contains English language strings of Minecraft (mojang-translations), for which no license was found.
- `org.codehaus.plexus:plexus-utils`: Ten of its source files carry the Apache License 1.1, and MXParser the Indiana University Extreme! Lab Software License 1.1.1. The FSF lists the Apache License 1.1 as incompatible with the GPL because of its prohibitions on the use of names, which the Extreme! Lab license has as well; the FSF does not list the latter. Paper bundles the same library, and the project owner decided to distribute it the same way (see the decisions in LICENSING.md).
- `studio.cubiq:cubiq-api`: Paper's API with Purpur's and Cubiq's changes, distributed under the GPLv3 like the server.
